# Simple Portfolio Template

A clean and responsive portfolio template. It's easy to customize and ready to showcase your personal information and projects.

## Features

-   Responsive design
-   Dynamic content loading from JSON files
-   "About Me" section with image and bio
-   Project listing
-   Social media links

## How to Use

1. Clone this repository.
2. Replace the content in `data/profile.json` and `data/projects.json` with your own information.
3. Add your images and icons to the appropriate folders.
4. Open `index.html` in your browser — no build process needed!
